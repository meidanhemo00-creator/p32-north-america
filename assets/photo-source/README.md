# Raw photo originals — not deployed

Sourced directly from the client's Google Drive folder
(`https://drive.google.com/drive/folders/10lusvDNRKLoiuFjieDz6t6SPAgJIJxwC`),
downloaded 2026-09-02. Fourteen real photographs, each 1920×1080 PNG,
named by their Drive filename (`8.png`–`25.png`, non-contiguous — that's
the full set the client uploaded to that folder).

This folder is intentionally **outside `public/`** so it is never bundled
into the static export or deployed to GitHub Pages — it's a full-resolution
archive to crop/reprocess from later, not a served asset. The optimized,
web-ready JPEGs actually used on the site live in `public/photos/` (see
that folder's README for the mapping and processing steps).
